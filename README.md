# iim

iim 是一个 Windows 优先的局域网即时通讯客户端，使用 Rust + Tauri 2 + Svelte 5 + TypeScript 开发。目标是提供类似飞秋/企业微信风格的无服务器内网沟通体验：同网段自动发现，复杂网络可配置种子节点和扫描网段，不依赖中间目录或转发服务器。

## 当前能力

- 桌面 IM 工作台：会话列表、局域网在线联系人快捷入口、聊天区、输入区工具栏、联系人、文件传输、详情/成员/安全/存储 Inspector、设置中心和深色主题。
- 自定义右键菜单：禁用原生浏览器菜单，支持复制、引用、转发、重新发送、撤回、详情和删除。
- 文本消息：本地 outbox、ACK 送达、已读回执、输入中提示、引用回复、会话草稿、消息收藏、表情回应、失败重试预算、手动重发和重复消息去重。
- 消息撤回：撤回包带签名，接收端校验撤回者必须是原消息发送者，撤回后正文清空但保留记录。
- 群聊：无服务器 fanout，群邀请同步成员列表，右侧可显示和编辑群名称、增减群成员并广播更新。
- 文件和文件夹传输：支持拖拽、粘贴、选择文件/文件夹、聊天气泡附件卡片、manifest、SHA-256 校验、TCP 拉取、断点续传、任务列表和打开接收目录。
- 截图入口：Windows 桌面版可启动系统截图 URI，截图后可粘贴发送。
- 联系人与会话管理：联系人资料卡、备注、分组、收藏、直接发起聊天、可信设备列表、移除旧信任、会话置顶、免打扰、归档、清空聊天记录、删除、未读、全局搜索、当前会话内搜索定位和按日期跳转历史。
- 网络发现：UDP 广播端口 `24250`，传输端口 `24251/24252`，支持广播开关、种子节点和 CIDR 扫描范围。
- 安全身份：Ed25519 设备身份、设备指纹、TOFU 首次信任、指纹变化拒绝、消息/ACK/群邀请/文件公告/输入中/已读/撤回/回应签名校验。
- 本地存储：SQLite 数据库、每安装随机数据库密钥、Windows DPAPI 保护密钥和身份文件；保存历史消息、联系人、会话偏好、传输任务和信任指纹，支持会话聊天记录 Markdown 导出和单会话历史清空。
- 桌面集成：系统托盘、最小化到托盘、桌面通知和存储位置打开。

## 开发运行

Windows 默认启用 SQLCipher。首次编译需要 Rust MSVC 工具链、Node.js、WebView2，并且需要满足 SQLCipher 的 OpenSSL 构建依赖：安装 Perl 后可使用项目默认的 vendored OpenSSL；或者安装 OpenSSL 并设置 `OPENSSL_DIR` 使用系统库。

```powershell
npm install
npm run tauri dev
```

## 生成二进制

```powershell
npm run build
cd src-tauri
cargo build --release
```

生成的可执行文件位于：

```text
src-tauri/target/release/iim.exe
```

## 验证命令

完整验收前运行：

```powershell
cd src-tauri
cargo fmt --check
cargo test
cargo build
cd ..
npm test
npm run build
```

## 生产验收重点

- 两台或多台 Windows 机器在同网段互相发现、单聊、群聊、已读、撤回和文件/文件夹传输。
- 禁用广播后通过种子节点或扫描网段发现可达 peer。
- 传输大文件时中断接收进程，再次收到 manifest 后断点续传并通过 SHA-256 校验。
- 首次信任后替换同一 peer 的指纹会被拒绝并显示网络安全告警。
- 托盘、通知、截图、拖拽、粘贴、右键菜单和设置中心在真实 Tauri 桌面环境中可用。
